# RAG Knowledge Assistant

An AI chatbot powered by Retrieval-Augmented Generation (RAG).  
Upload PDFs or text files, and ask questions with answers grounded in your documents.

## Features
- Document ingestion (PDFs, text)
- Embedding + vector search (FAISS)
- Retrieval-Augmented Generation pipeline
- Interactive Q&A interface (Streamlit)

## Tech Stack
- Python
- LangChain
- FAISS
- OpenAI / Hugging Face models
- Streamlit


## Getting Started
1. Clone repo
2. Install dependencies: `pip install -r requirements.txt`
3. Run app: `streamlit run app.py`
